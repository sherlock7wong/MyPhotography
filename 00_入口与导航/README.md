## 本地版本管理

- 当前整理基线为两套仓库各自的 `main` / `v1.0.1`，各保留1条当前提交。此前 `local/*`、旧分支及旧源码副本统一从 `90_历史版本与恢复备份/历史版本清理恢复_history-cleanup-recovery_2026-10-30/` 按原路径恢复，不再保留为活动代码入口。版本标签只表示文件快照，业务验收状态仍以原证据为准。
- [保存版本脚本](../20_源码与运行工程/版本管理_version-control/保存版本_save-version.ps1)：在项目根目录的 PowerShell 中执行，例如：

```powershell
& './20_源码与运行工程/版本管理_version-control/保存版本_save-version.ps1' -Message '说明本次修改' -Paths @('AGENTS.md') -Validation '写明实际完成的检查'
```

- 用 `git log --oneline --decorate -10` 看记录，用 `git branch` / `git tag --list` 核对当前入口。本轮按用户要求仅保留main与v1.0.1，额外local标签统一移除；后续新开发遵循届时明确的版本要求。被忽略的私有数据、缓存和原始媒体不由源码Git备份。
- 目录联接与硬链接由既有整理结构维护，Git 不保证恢复这些 Windows 链接关系；恢复前先比较差异和已有迁移映射，不直接 `reset --hard` 清除工作内容。
