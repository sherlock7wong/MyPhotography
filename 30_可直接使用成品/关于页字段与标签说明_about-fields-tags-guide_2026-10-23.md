# 关于页字段与技能标签说明

日期：2026-10-23。适用于本机摄影网站当前关于页后台；部署准备包也使用同一组控件，尚未发布到线上。

- 后台：http://127.0.0.1:5173/admin/index.html#about
- 前台：http://127.0.0.1:5173/about/index.html

## 你标出的六个位置

| 后台字段 | 用白话说，它做什么 | 前台在哪里能看到 |
| --- | --- | --- |
| 合作状态 | 告诉访客你是否接受约拍、委托或合作。 | 肖像旁的个人资料表中，Availability 一行。资料表模块关闭时这行也不显示。 |
| 个人资料简短介绍（原“搜索用简短简介”） | 给搜索程序读取的一句话个人介绍。 | 通常不单独出现在正文里；它写入页面的个人资料结构化信息。只有“个人简介”留空时，才作为正文的备用介绍。 |
| Focus / Skills 标签 | 管理你想展示的摄影方向、技能或兴趣。 | 前台 Skills & Focus 区域，顺序与后台相同。 |
| 肖像图片说明 | 用文字描述照片，方便读屏软件读取，或在图片无法加载时替代图片。 | 正常显示照片时不会印在图片下面，也不是鼠标悬停提示。 |
| 路径装饰文字 | About 大标题下面的一行小字，例如 /about。 | 留空时不显示；填入并保存后显示。它只是装饰，不会修改浏览器网址或页面跳转。 |
| 本页搜索摘要与分享预览 | 设置网页对外展示的标题、摘要与分享图片。 | 标题用于浏览器标签页；摘要和分享信息供搜索及分享平台读取，后台可以展开查看示例。它不修改 About 正文、肖像或技能标签。 |

## 技能标签怎么操作

1. 在“输入新技能标签”填写一项，点“添加标签”或按回车。中文输入法选词时的回车不会误添加。
2. 直接修改每项文字；用上移、下移调整前台顺序；点删除移除该项。标签可以全部删除。
3. 点“保存本页”，再刷新前台检查。输入框里尚未点添加的新文字也会在保存时加入。
4. 不想保留本页尚未保存的更改，可以点撤销。重复标签、空名称会提示处理，避免误保存。
5. 导出备份会包含当前未保存的标签草稿，但不会因此改动已保存的网站数据。导出数据可能包含私人内容，请自行妥善保管。

## 搜索和分享为什么没有在正文变化

“个人资料简短介绍”是给程序读取的个人介绍；页面底部的“搜索摘要与分享预览”是整张网页的搜索与分享设置，两者用途不同。

修改底部的网页标题，保存后可看浏览器标签页；修改摘要或分享图片，正文不会变化。搜索网站和聊天软件是否采用、何时更新这些信息由它们决定，可能使用缓存。后台预览用于核对已填写内容，不代表外部平台已经收录。127.0.0.1 只在本机可访问，外部搜索和分享平台无法直接访问这个地址。

规范网址只是告诉搜索程序该页的正式地址，不会把访客跳转过去。不要为了更改正文而修改这些设置。
