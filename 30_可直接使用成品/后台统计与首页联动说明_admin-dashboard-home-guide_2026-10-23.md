# 后台统计与首页联动说明

版本日期：2026-10-23；统计口径于 2026-10-24 续修。适用于当前本机共享网站和本轮部署准备代码；本机入口：http://127.0.0.1:5173/admin/index.html#dashboard 。本轮没有公开上线或执行真实 D1 迁移。

## 数据统计

“管理概览”已改为“数据统计”。旧页面快捷入口、当前内容记录、保存恢复说明及旧稿提示区已经移除；侧栏可进入五页编辑及导出数据备份。旧浏览器原稿没有删除。

- 内容：项目数量、照片总数、摄影分类、留言总数及未读数量。照片仅统计已加入 Photography 总览或当前分类页展示范围的作品，按作品 ID 去重；首页、项目页复用不会累加，头像、封面和二维码不计入。草稿或隐藏作品可计入“全部”，能公开展示的数量另列“前台可见”。
- 分类：每个当前摄影分类的已配置作品、允许前台显示的作品和精选数量；City Humanity 与其他分类一致。未加入摄影展示范围的项目上传不生成“未分类”统计行。旧城市专题不再单独统计或编辑。
- 访问：今日及累计浏览次数、按浏览器去重的访客数、最近 14 天趋势及当前五页分布；旧城市专题的历史记录保留在存储中，不计入当前仪表盘。全部按北京时间统计。
- 留言阅读：管理员实际进入收件箱显示留言，或切换到另一条留言时计一次；编辑备注、处理状态或重绘界面不会重复计数。此统计不自动改变“未读／已读”的处理状态。

统计从启用后记录。启用前显示“未统计”，不会虚构历史访问。后台、图片请求和后台读取前台模板不计入前台访问。访客使用本机浏览器随机标识去重，不等于真实人数；同一人换设备、换浏览器或清除存储可能被分别计数。页面必须实际打开且可见，未运行网页脚本的访问不会计入。

服务不可用时显示“—”和原因，不用 0 代替错误；右上“刷新统计”可重新读取。累计 50,000 条访问／阅读事件后停止新增并保留历史，仪表盘会提示维护。访问统计独立于网站内容，读取统计不会改内容版本。

## 首页原片与成片

首页照片名单仍自动来自摄影总览中已发布、公开且勾选“精选”的作品。

1. 在后台“首页”打开“精选照片的原片与成片”。
2. 选择一张当前首页精选，只上传这张照片对应的原片网页图片，并填写它的标题、原片说明、光线／色调／细节说明。
3. 成片直接使用该摄影作品当前的图片，无需在此再上传一份。
4. 保存本页后，前台点击照片、编号、方向键，或在手机滑动照片条，都会读取同一作品自己的配置。

作品排序和更换成片不会错配原片。新增精选尚无原片时只展示成片；清空某张的原片同样只展示成片，不用滤镜冒充修图前后。取消精选或隐藏作品会保留配置；未公开作品的原片配置不会发给前台访客。原有全局配对只在成片精确匹配该作品、且还没有新配置时兼容读取；旧上传文件和设置不删除。

## 搜索摘要与分享预览为何不改变正文

这个模块管理浏览器标签、搜索结果和分享卡片的资料，不负责修改网页里的正文。页面主标题和介绍应在对应内容模块中修改。

| 字段 | 实际用途 | 保存后在哪里看 |
| --- | --- | --- |
| 浏览器标签与搜索标题 | 浏览器标签文字，也提供搜索／分享标题 | 打开对应前台，查看浏览器标签；后台下方预览随输入更新 |
| 搜索结果摘要 | 给搜索结果及分享卡片提供简介 | 页面 head 的 description 与分享标签；搜索引擎可能自行选择其他正文 |
| 链接分享图片 | 分享卡片封面 | 后台分享预览；不替换网页里的作品照片 |
| 规范页面地址 | 告诉搜索引擎本页正式地址，合并重复页面信号 | 页面 canonical 标签；不会把访客跳转到这个地址 |

标题、摘要和分享图留空时使用页面默认信息。后台预览是效果示意，不代表搜索平台已更新索引或分享缓存。保存后，本机服务与 Worker 均会把对应元数据直接写入返回的原始 HTML；正文保持原内容。分类页使用自己的分类设置，切回总览时恢复总览设置。

127.0.0.1 是本机地址，外网搜索引擎及社交平台无法访问它。正式公开站点的实际搜索标题、摘要和分享卡片，由对应平台抓取、选择并缓存，保存后不保证即时变化。[Google 官方说明](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)；[Open Graph 规范](https://ogp.me/)。
