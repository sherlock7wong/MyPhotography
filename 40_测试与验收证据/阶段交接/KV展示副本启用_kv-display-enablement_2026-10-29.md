## 已实现的行为

1. D1继续保存内容、媒体权限和副本台账；B2保存三角色源文件，其中原图私有；KV另存展示图及缩略图。访客URL保持原样，不需要在两个内容数据库分别编辑。
2. 公开读取先检查完整上传、角色和当前已发布引用，再读KV。已有副本命中返回 `X-Photo-Source: cloudflare-kv`；KV未就绪时最多一次B2降级，原图始终走管理员鉴权和私有B2。
3. KV键包含上传ID、角色、SHA，保持不可变。迁移与上传完成阶段有界读取源文件、核对长度/SHA，写入后完整读回核验才标ready。普通ready图片采用流式返回，不对每个访客请求重算整图SHA。
4. 网站配置800,000,000 B预算，包含每键2048 B余量；D1原子保留容量并限制每日800次KV写入尝试。未确认写入继续占用预算，明确恢复需等5分钟，不自动重复写。
5. 新上传仍先完成B2三角色文件；副本阶段中断会保留已上传文件，既有恢复ID支持继续，避免重新上传原图。客户端完成请求等待上限改为180秒，后台显示副本数量和容量。
6. B2授权与桶初始化在同一运行实例内有界复用、合并并发请求，并处理失效/限额冷却；不保证不同运行实例共用一个授权或每天只有一次授权。

## 免费边界（本轮官方核验2026-10-29）

| 限制 | 官方Free额度或本网站预算 |
| --- | --- |
| KV账户容量 | 1GB；单值最多25MiB |
| KV每日读 / 写 | 100,000读 / 1,000写，账户共享 |
| Workers每日请求 | 100,000，账户共享；当前所有页面、静态文件、API和图片均经过Worker |
| 网站KV保护预算 | 800,000,000 B（含每键余量）、800次写入尝试/UTC日；不是账户实时剩余额度 |
| 日额度重置 | 00UTC，即北京时间08:00；不同IP不绕过账户额度 |
| 一致性 | KV更新可能需要60秒或更久传播，不能保证立即全球一致 |

KV没有按出站流量收费的单独额度，不代表网站无限访问；Workers、KV和账户其他资源仍各自受限。本站预算只能约束本应用，无法保证账户其他应用不消耗官方额度。没有启用付费超额方案。参见[KV定价](https://developers.cloudflare.com/kv/platform/pricing/)、[KV限制](https://developers.cloudflare.com/kv/platform/limits/)、[Workers限制](https://developers.cloudflare.com/workers/platform/limits/)、[KV一致性](https://developers.cloudflare.com/kv/concepts/how-kv-works/)。
