# 后台中文逐页编辑交接

事项日期：2026-10-21（Asia/Shanghai）

本轮已在本地完成后台中文化、按前台页面拆分编辑、静态内容绑定和同源云端适配。已生成并核对部署预备包；没有推送、部署、迁移生产数据库或处理真实客户数据。

## 已实现的对应关系

| 后台入口 | 对应前台 | 编辑范围 |
|---|---|---|
| 首页 | `/Home/index.html` | 主标题、档案标签、印章、独立简介、按钮、五张可见选片及默认位置、分类卡片、页脚 |
| 关于页 | `/about/index.html` | 个人资料、肖像、简介、技能、经历、相框、档案、章节标题、页脚 |
| 项目页 | `/Project/index.html` | 页头、档案、印章、项目卡片、项目分类及查看按钮的实际跳转 |
| 摄影页 | `/photography/index.html` 与关联分类视图 | 作品及拍摄参数、精选、分类页标题/介绍/封面/印章/风格筛选/搜索摘要、默认视图与排序、访客本机收藏 |
| 城市人文页 | `/CityHuman/index.html` | 独立作品、筛选主题、默认筛选/排序/视图、封面、档案、完整详情参数与字段标签 |
| 联系页 | `/Contact/index.html` | 联系资料、方法卡片、二维码、表单标签和反馈、校验/暂停设置、五张胶片照片、状态、页脚 |

每页都有模块显示与本页搜索/分享设置。导航、品牌、默认摘要和动效集中在“全站共用与接口”；收到的联系页留言放在独立收件箱。首页简介与关于资料分离；摄影作品会被首页选片引用，分类会被首页/项目卡片引用，界面标明关联规则。

统一入口为 [中文后台](http://127.0.0.1:5173/admin/index.html)。`admin/profile` 等旧独立页面以及 `backendProject/backendContact/backendMessages` 已改为对应编辑页的兼容跳转，没有删除原始素材。

## 本轮审查修正

- 原来个人资料同时影响首页和关于页、首页配置散落在设置中，现改为按页维护。
- 城市人文原有 9 张作品与筛选保留并接入共享数据，不再使用另一套硬编码私有数组。
- 分类切换、排序和筛选后保留后台设置的分类文案、封面及搜索摘要；首页与项目卡片支持 `?category=` 定位分类。
- 项目、图库、分类、时间线、联系卡片和照片条清空后，不会复活原 HTML 示例。
- 修正模块选择器和页面布局覆盖 `hidden` 的问题；测试核对实际显示状态。
- 首页后台选片对应五个真正可见的照片位，不再让装饰占位吞掉选片；只有一张时可正常选中。
- 保存/图片处理中锁定编辑，防止发出 A 却把稍后输入的 B 标为已保存。容量错误、存储禁用、上传部分失败和云端版本冲突都保留草稿并允许重试或导出。
- 联系页使用真实的成功/失败结果：失败保留输入，暂停提示不会被普通按钮文案覆盖；本地留言与云端留言明确区分。
- 公开投影剔除未发布/隐藏内容及留言，分类关联以 ID 优先。管理员仍保留完整原始文档；媒体 URL 另属公开资源，不作为私密文件存储。

## 数据与接口

原 `wong.cms.data` 结构沿用，新增逐页覆盖存于 `settings.pageContent`，城市数据存于 `settings.cityContent`。保留既有作品、分类、项目、联系和资料字段，未清除用户浏览器存储。静态字段定义与前台绑定共用 `shared/cms-pages.js`。

本地模式只写当前浏览器。云端模式复用现有 `/api/admin/login`、`session`、`logout`、`state`、`upload`，以及 `/api/public-state.js`、`public-version`、`contact`。保存携带 `version`，409 不覆盖；请求有超时，云端读取失败显示错误并隐藏示例正文。公开设置不存密钥。没有新增数据库迁移。

后台新导入本地图片采用不超过 1600 像素、每张不超过 512 KiB 的预览，原照片不修改；云端图片使用现有 8 MB、JPEG/PNG/WebP/GIF 上传接口并保存 `/media/…` 地址。导出 JSON 包含当前草稿与留言，不能代替生产 D1/R2 的完整备份。
