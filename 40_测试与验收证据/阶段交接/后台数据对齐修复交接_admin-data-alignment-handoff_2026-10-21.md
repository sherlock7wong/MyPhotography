# 后台数据对齐修复交接（2026-10-21）

本轮延续已完成的中文逐页后台，修复用户反馈的“保存后前台不变、初始数据对不上”。范围为当前 5173 本机网站和既有部署准备包；没有推送 Git、公开上线或写入真实云端数据库。

## 核实的原因

1. 当前前后台路由确实指向现用源码，未指到旧备份目录；但旧 CMS 默认内容覆盖了原页面的图片、段落、标签、时间线和摄影作品数组，因此后台读取的内容与原前台不一致。
2. 旧正常保存依赖浏览器 localStorage；此前单个浏览器上下文和 API 拦截测试不能证明真实跨浏览器共享保存。没有读取到用户实际浏览器的存储，不能认定用户本人用了多个浏览器。
3. 项目主题选择会被关联分类覆盖；摄影分类回退可能混入仅供总览的作品；联系页文字选择器会匹配动效装饰。这些显示映射已一并修复。

- 根 node start-server.js 提供真实本机 HTTP 登录、内容读写、上传与留言接口。前后台在 server 模式读取同一份持久化文件，保存成功才更新共享状态；其他浏览器和服务重启后继续读取已保存内容。
- 本机网站默认不再选择浏览器模拟保存。旧 localStorage 不清空，存在旧数据时可单独导出；旧稿不会未经核对覆盖共享网站。

- 现有 Worker 构建默认内容、server ESM／JSON、client UMD 与源码种子保持一致；已更新本地准备构建包。
- 当前操作说明 Markdown／HTML 和入口索引已同步共享保存、上传、接口与恢复步骤。

- 真实源码：20_源码与运行工程/shared/、admin/、本地服务_local-server/、内容同步_content-sync/。
